# 诗心鉴

「你与哪位中国诗人，隔世相知？」

一个中国古典诗词文化娱乐匹配测试 V1。用户完成 32 个现代生活情境选择后，系统依据八维诗心向量与 16 位诗人原型做确定性匹配，并展示 Top 1 / Top 2 / Top 3、八方诗盘、诗作推荐与诗心笺。

## 本地运行

```bash
npm install
npm run dev
```

生产检查：

```bash
npm run build
npm run start
```

## 算法说明

- 每道题只影响两个维度；四个选项分别使用 `-3 / -1 / +1 / +3` 与反向维度值。
- 32 题累积后，八维原始分按 `50 + raw / 24 * 50` 归一化至 0–100。
- 每位诗人拥有八维 0–100 原型向量；当前匹配使用八维平均绝对距离的反向值排序。
- 展示分数是体验层映射，不是心理学准确率，也不代表“你就是某位诗人”。
- 文案明确将结果定义为“诗心原型 / 创作气质上的相似”，不是历史人物真实人格诊断。

## 产品边界

V1 anonymous、本地恢复进度、不依赖数据库、不接 AI API。结果与进度只保存在当前浏览器；分享按钮复制结果文案，后续可接入真正的 9:16 图片导出与分享链接。

## 主要文件

- `app/page.tsx`：题库、诗人数据、匹配逻辑和页面交互
- `app/globals.css`：东方纸笺视觉系统、响应式布局和 reduced-motion
- `app/layout.tsx`：SEO metadata 与全局布局
- `设计.md`：研究、量表、题库及产品设计依据
